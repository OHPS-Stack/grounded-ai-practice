# Brand icons — third-party marks used in figures

Eight monochrome brand icons, fetched 2026-08-14 from the Simple Icons
CDN (`cdn.jsdelivr.net/npm/simple-icons@latest/icons/<name>.svg`) for
the pilot-unit architecture figure drawn by
`tools/build_pilot_figures.py`.

- `amd.svg`, `intel.svg`, `ubuntu.svg`, `docker.svg`, `ollama.svg`,
  `pytorch.svg`, `vllm.svg`, `windows.svg`

Simple Icons publishes these shapes under CC0; the marks themselves
remain trademarks of their owners and are used here unmodified, for
factual identification of the software and hardware the document
describes — not as endorsement, and never edited or redrawn. The
figure script tints them a single ink colour at render time (the
files themselves are untouched), per the creator's 2026-08-14
direction that monochrome versions are preferred where brand colours
would be louder than the document.

If a mark's owner objects or Simple Icons withdraws an icon, replace
the icon with a plain-text wordmark label in the figure script and
delete the file here.
